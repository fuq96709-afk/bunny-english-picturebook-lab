# 小白兔英语绘本 · AI 内容增长实验室

**账号方向：用15秒讲一个小白兔的生活故事，让家长能立刻陪孩子说一句英语、做一次互动。**

家长决定这条值不值得停下、收藏或下次打开；孩子通过看懂故事、跟着说或数，参与一次。先写清这两件事，再生成画面。每集围绕一个能演出来的英语动作，例如「跟小兔数到三」，让孩子的参与和故事结果发生关系。

## 内容怎么做

- **主角**：拟人化小白兔，白色毛发、粉红耳朵、大眼睛。保持角色可辨识，用菜园等真实环境和手机生活记录质感，保留绘本的温暖与童趣。
- **成片**：12–15秒，简单英语配音、中英字幕、轻音乐。单集先写一个主要参与任务，留出能跟说的时间。
- **脚本优先**：用可见动作写故事。比如「橙色萝卜露出一点」比「气氛紧张」更容易生成、剪辑和验收。
- **封面和脚本一起做**：封面给家长一个具体用途，标题交代故事，开场兑现故事问题。拔萝卜这集的封面可写「陪孩子用英语数到3」，标题可写「数到3，帮小兔拔萝卜！」。
- **抖音**：目前以小白兔英语绘本和短视频留存实验为主。
- **小红书**：保留 AI 实践、制作过程和项目复盘方向。可探索亲子英语玩法笔记，例如「用拔萝卜陪孩子数到3」。可试3:4封面。定位和后台数据待补充，单独观察。

## 当前实验

原片约第3秒出现求助，约第5.5秒才给出数数字幕。先用同一份原片对照第3秒的两句邀请：

- A 版：*Help me, please!*「请帮帮我！」
- B 版：*Count with me!*「跟我一起数到三！」

先让不同家长各看一版前4秒，问「如果孩子就在你旁边，你现在会让他做什么？」。如后续用新故事验证，主看相同发布后时长的5秒观看率，辅助看2秒跳出率和完播率。原片对照与新故事发布属于两个阶段。
