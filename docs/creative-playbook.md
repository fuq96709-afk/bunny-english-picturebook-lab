# 创作方法与脚本

## 从家长的真实选择倒推

- **刷到时**：家长看懂能带孩子做什么了吗？看懂后还划走，追问这个活动是否值得停；没看懂，检查首帧动作、封面和字幕。
- **看下去**：孩子知道怎么参与了吗？如果孩子没跟，分别检查邀请是否清楚、回应时间是否够，以及他是否愿意参与。数到三时，让画面立刻给出结果。
- **看完后**：家长在哪个场景会再打开？关注后希望下一集能做什么？收藏和关注是行为线索，原因靠家长反馈和反复观察来验证。

先问真实发生过的事：「上次给孩子放英语内容是什么时候？放了什么？后来有再打开吗？」给家长看前4秒后暂停，再问「如果孩子就在你旁边，你现在会让他做什么？」先听自发回答，再问原因。同行的评论可以作为创作交流，家长需求另找证据。

## 15秒怎么审

| 时间 | 审片问题 |
|---|---|
| 0–2秒 | 第一帧能看懂小兔遇到了什么吗？ |
| 2–5秒 | 家长能不能说明孩子接下来要做什么？ |
| 5–8秒 | 画面有没有进展？孩子有时间跟上吗？ |
| 8–11秒 | 参与得到清楚的结果了吗？ |
| 11–15秒 | 故事还有一个新的情绪或动作回报吗？ |

逐秒写下画面变化、台词和字幕、观众的当前期待。问「删掉这一秒，会少看懂什么、少期待什么，或少一次开口机会？」。停顿可以服务跟读或表情，看片时检查它的作用。

## 《小兔拔萝卜》B版声画脚本

时间按原片画面与烧录字幕估读，准确起声和跟读空隙需要在剪辑中听音确认。

| 时间 | 画面 | 配音／字幕 |
|---|---|---|
| 0–3秒 | 双爪抓叶往后拔，萝卜卡住。 | *Oh no! It’s stuck!*／哎呀！拔不动啦！ |
| **3–5.5秒** | 转向镜头、伸爪，邀请随动作和配音出现。 | ***Count with me!*／跟我一起数到三！** |
| 5.5–9秒 | 回头抓牢叶子，露出一点橙色，数到三拔出来。 | *One, two, three!*／一、二、三！ |
| 9–12.5秒 | 小兔抱着萝卜坐倒，低头确认，再抬头笑。 | 约第11秒出现 *We did it!*／我们成功啦！ |
| 12.5–15秒 | 把萝卜递向镜头，收在分享动作上。 | 约第13秒出现 *This is for you!*／这个送给你！ |

制作原片对照时，A版使用原邀请，B版替换第3秒的配音和中英字幕。画面、时长、数数起点、高潮位置、封面和标题使用同一版。生成新集时，把画面、动作、台词和字幕放进同一份脚本，再进入生成。

## 封面与标题

底图选小兔抓着叶子往后用力的一帧，保留小兔表情和卡住的萝卜。主文案「陪孩子用英语数到3」，标题「数到3，帮小兔拔萝卜！」。单独测试封面时可用同一张底图比「陪孩子用英语数到3」和「小兔拔不动萝卜」，收集封面曝光量、点击率或家长预览选择。首屏字幕的两种价值表达也可以另开一轮测。
