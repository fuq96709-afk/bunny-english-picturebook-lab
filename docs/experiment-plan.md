# 30天实验与记录模板

原计划为2026年11月11日–12月10日，约19条，每周4–5条。目标是找到至少两种可重复使用、留存表现较好的故事结构。

| 阶段 | 验证方向 |
|---|---|
| 第1周 | 首帧能否让人看懂困难；随后单测邀请是否具体。 |
| 第2周 | 对比互动求助、搞笑反转、治愈分享。 |
| 第3周 | 比较真实场景、角色写实程度和拍摄质感。 |
| 第4周 | 把有改善信号的结构换到新故事里复测。 |

## 当下怎么排

1. 同一原片用 A、B 两种邀请做家长预览，记录他们能否在前4秒复述玩法及犹豫原因。
2. 若发布下一集，用类似故事结构再看5秒观看率，例如用「推不动南瓜」承接数数玩法。把新故事与旧作的比较视为观察结果。平台顺序发布会同时受到触达人群、时间和来源影响。
3. 邀请验证后，可单测数数起点、高潮后动作或封面文字。封面与视频内容分别测，以免结果无法归因。
4. 按发布后24小时、72小时、7天收集快照。比较相同作品年龄、相近时长和流量构成。播放规模变小也继续观察留存和有效互动。小样本优先看同一方向能否跨作品重复。
