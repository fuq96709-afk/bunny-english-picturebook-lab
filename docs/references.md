# 调研资料

| 资料 | 怎么用 |
|---|---|
| [MrBeast 与 Lex Fridman 的访谈](https://lexfridman.com/mrbeast/)；[YouTube 留存报告说明](https://support.google.com/youtube/answer/9314415?hl=en) | 让封面、标题和开场兑现同一预期，把留存变化对到实际画面。 |
| [Made to Stick 作者框架](https://heathbrothers.com/wp-content/uploads/resources/mts-made-to-stick-model.pdf) | 用一个简单、具体的故事问题制造好奇，例如数到三能不能拔出萝卜。 |
| [The Mom Test 作者网站](https://www.momtestbook.com/) | 访谈追问过去实际发生的事，再听家长自发复述玩法。 |
| [美国教育科学研究所：互动式绘本共读](https://ies.ed.gov/ncee/wwc/Intervention/271) | 借用大人邀请、孩子回应的互动方式。15秒视频的学习效果仍待验证。 |
| [Trustworthy Online Controlled Experiments](https://www.cambridge.org/core/books/trustworthy-online-controlled-experiments/D97B26382EB0EB2DC2019A7A7B518F59) | 先定假设、指标和对照，明确自然发布比较与随机实验的证据差异。 |
| [抖音安全与信任中心](https://trust.douyin.com/transparency)；[小红书创作服务平台](https://creator.xiaohongshu.com/) | 查平台公开解释和各自后台数据，分别建立基线。 |
| [KuaiRand](https://github.com/chongminggao/KuaiRand) | 快手研究项目提供观察曝光偏差的例子，提醒我们记录流量来源。 |
| [PySceneDetect](https://github.com/Breakthrough/PySceneDetect) | 批量提取切镜时间，辅助把原片、字幕和留存对齐。 |
